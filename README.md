# 대한민국 인프라 소외지역 실시간 분석 지도 🛰️

> **초고화질 위성 한국어 지명 및 전국 18대 인프라 정밀 분석 웹 GIS 플랫폼**  
> 대한민국 전국 229개 기초지자체(시·군·구) 전수 및 18대 대표 취약지구의 **13대 핵심 인프라 결핍 진단 지표**를 실시간으로 스트리밍·분석합니다.

---

## 🌟 주요 핵심 기능

1. **전국 229개 전 행정구역 실시간 검색 & 정밀 진단**
   - 17개 광역자치단체 + 229개 시·군·구 + 주요 행정구 및 도서(울릉, 독도, 백령, 흑산, 마라도 등) 전수 검색 지원
   - 실시간 스마트 자동완성 및 부분 지명/초성/키워드 매칭
   - 검색 시 26km 분석 반경 버퍼 원 실시간 투사 및 13대 지표 자동 팝업

2. **13대 핵심 인프라 실시간 진단 지표**
   - 🚨 **응급의료**: 골든타임 30km 권역외상·응급실 접근성
   - 🚆 **교통/철도**: 광역철도·지하철 및 대중교통 배차간격 진단
   - 📚 **교육**: 학령인구 추이 및 학교/도서관 인프라
   - 🎭 **문화/체육**: 공연장·영화관·공공체육시설 보급
   - 🚒 **소방/안전**: 119안전센터 골든타임(7분) 도달률
   - 🏠 **복지/돌봄**: 독거노인·취약계층 맞춤 복지인력
   - 📡 **통신/디지털**: 5G 기지국 커버리지 및 통신 음영
   - 💧 **상수도/물**: 광역·지방상수도 보급률 및 수원 안전
   - ⚡ **에너지/난방**: 도시가스(LNG) 및 지역난방 배관망
   - 🛒 **생활/상권**: 종합 쇼핑·대형마트·전통상권
   - 🌲 **환경/생태**: 친환경 녹지율 및 폐기물 처리
   - 💼 **일자리/산업**: 국가·일반산업단지 및 양질의 일자리
   - 📉 **소멸위험**: 인구소멸위험지수 실시간 산출

3. **고해상도 위성 지도 & 한국어 지명 라벨 상시 탑재**
   - Esri 초고화질 글로벌 위성 타일 베이스맵
   - 도로망을 배제하고 오직 행정 지명만 깔끔하게 노출하는 고화질 한국어 라벨 상시 가동
   - 불필요한 레이어 컨트롤 박스를 제거하여 지도를 쾌적하게 활용

4. **패널 버튼 클릭 시 지도 핀(마커) 원터치 숨김 시스템**
   - 패널에서 13대 인프라 버튼 클릭 시 지도 핀을 자동으로 숨겨 결핍 권역 버퍼를 깔끔하게 시각화
   - 패널 상단 `📌 핀 숨기기 / 📍 핀 표시하기` 토글 버튼 제공

5. **모든 기기 반응형 지원 (데스크톱 / 태블릿 / 모바일)**
   - 데스크톱/태블릿: 좌측 13대 진단 패널 접기/펼치기 (`◀/▶` 핸들)
   - 모바일: `[🗺️ 지도 화면]`과 `[📋 13대 진단 패널]` 원터치 뷰 스위처
